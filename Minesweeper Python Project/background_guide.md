# Minesweeper Pro Background Customization Guide

This guide explains how to customize the background image in Minesweeper Pro.

## Using Online Images

1. In the game sidebar, select "Online URL" under Background Source
2. Enter the URL of an image in the "Background Image URL" field
3. Press Enter to apply the background

### Preset Backgrounds

For convenience, we've included several preset backgrounds:
- Blue Geometric: A subtle blue pattern
- Dark Pattern: A dark hexagonal pattern
- Light Abstract: A clean white background
- Tech Circuit: A technology-themed background

Click on any of these presets to instantly apply them.

## Using Local Images

1. Place your image files in the `backgrounds` folder or the main game directory
2. In the game sidebar, select "Local File" under Background Source
3. Choose your image from the dropdown menu
4. A preview of the selected image will be shown

### Supported Image Formats

The following image formats are supported:
- JPEG/JPG
- PNG
- GIF
- BMP

### Tips for Good Background Images

- Use images with subtle patterns that won't distract from gameplay
- Images with dimensions of at least 1920x1080 work best
- Lighter images may need a higher opacity setting for the game board
- Abstract patterns often work better than detailed photographs

## Troubleshooting

If your background doesn't appear:
- Make sure the image URL is correct and accessible
- Check that the image format is supported
- Ensure the image file isn't corrupted
- Try refreshing the page

If you're using a local file and it doesn't appear in the dropdown:
- Make sure it's in a supported format
- Try placing it directly in the main game directory
- Restart the application

## Creating Your Own Backgrounds

You can create custom backgrounds using image editing software like:
- Adobe Photoshop
- GIMP (free alternative)
- Canva (online tool)

Save your creations in one of the supported formats and add them to the game directory.

Enjoy customizing your Minesweeper Pro experience!
