# 🐍 Snake Game

A classic Snake game with modern features, created by asadullah48 (GitHub: [@asadullah48](https://github.com/asadullah48))

![Snake Game Screenshot](https://raw.githubusercontent.com/asadullah48/snake-game/main/images/game_screenshot.png)

## ✨ Features

- 🎮 Classic snake gameplay with intuitive controls
- 🎯 Multiple difficulty levels (Easy, Medium, Hard)
- 🏆 High score tracking system
- 🎁 Special bonus food items worth extra points
- ⏸️ Pause/resume functionality
- 🌐 Web version using Streamlit for online play

## 🚀 Play Online

You can play the web version of this game directly in your browser!

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://snake-game-asadullah48.streamlit.app/)

## 🖥️ Local Installation

### Prerequisites

- Python 3.7+
- Pygame (for desktop version)
- Streamlit (for web version)

### Installation Steps

1. Clone this repository
```bash
git clone https://github.com/asadullah48/snake-game.git
cd snake-game
```

2. Install required packages
```bash
pip install -r requirements.txt
```

3. Run the desktop version
```bash
python snake_game.py
```

4. Or run the web version with Streamlit
```bash
streamlit run streamlit_snake.py
```

## 🎮 How to Play

- Use arrow keys (desktop) or direction buttons (web) to control the snake
- Eat red food to grow longer and earn points
- Yellow food items are special and worth 3 points!
- Avoid hitting walls or your own body
- Press 'P' to pause the game (desktop version)
