## 📥 Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/asadullah48/python-portfolio.git
   cd python-portfolio
   ```

2. Create a virtual environment and activate it:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```

## 🔧 How to Add Project Screenshots

1. Create a folder for each project in the `screenshots` directory
2. Add screenshots with consistent dimensions (recommended: 1280x720)
3. Update the project data in `app.py` to include these screenshots

## 📝 Adding New Projects

To add a new project to the portfolio:

1. Add project details to the `projects` list in `app.py`
2. Include relevant screenshots in the `screenshots` directory
3. Deploy the project to Streamlit if applicable and update the link

## 🚀 Deployment

This portfolio is deployed on Streamlit Cloud. To deploy your own version:

1. Fork this repository
2. Connect your fork to Streamlit Cloud (https://streamlit.io/cloud)
3. Deploy the app with the default settings
