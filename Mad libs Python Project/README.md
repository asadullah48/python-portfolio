# 🎮 Mad Libs Adventure

![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=Streamlit&logoColor=white)
![Python](https://img.shields.io/badge/Python-3.8%2B-blue?style=for-the-badge&logo=python)
![Pillow](https://img.shields.io/badge/Pillow-8A2BE2?style=for-the-badge&logo=python&logoColor=white)

A professional, interactive **Mad Libs game** built with Python and Streamlit. Fill in the blanks, generate hilarious stories, save your favorites, and share them with friends!

👉 **Live Demo**: [![Hugging Face Spaces](https://img.shields.io/badge/🤗%20Hugging%20Face-Spaces-blue)](https://libsgenerator.streamlit.app/)

---

## ✨ Enhanced Features

- **Multiple Themes**: Fantasy, Sci-Fi, Pirate, Zombie, and Superhero stories
- **Professional UI/UX**: Beautiful background, styled components, and intuitive layout
- **Story History**: Save and revisit your previously created stories
- **Progress Tracking**: Visual progress bar shows completion status
- **Random Fill**: Generate stories quickly with random inputs
- **Tabbed Interface**: Organized sections for creating stories, viewing history, and learning about the app
- **Downloadable & Shareable**: Save your Mad Libs as a `.txt` file or share them directly
- **Visual Customization**: Choose accent colors to personalize your experience
- **Celebration Effects**: Balloon animations on story generation!

## 🚀 How to Run Locally

1. **Clone the repo**:
   ```bash
   git clone https://github.com/yourusername/Mad-Libs-Adventure.git
   cd Mad-Libs-Adventure
   ```

2. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**:
   ```bash
   streamlit run main.py
   ```

4. **Open in browser**:
   The app will automatically open in your default web browser, or you can visit `http://localhost:8501`
