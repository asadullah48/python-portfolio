# 🎮 Mad Libs Generator with Streamlit

![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=Streamlit&logoColor=white)
![Python](https://img.shields.io/badge/Python-3.8%2B-blue?style=for-the-badge&logo=python)

A fun, interactive **Mad Libs game** built with Python and Streamlit. Fill in the blanks, generate hilarious stories, and download them!

👉 **Live Demo**: [![Hugging Face Spaces](https://img.shields.io/badge/🤗%20Hugging%20Face-Spaces-blue)](https://huggingface.co/spaces/asadullah48/mad-libs) *(Deploy yours below!)*

---

## ✨ Features
- **Multiple Themes**: Fantasy, Sci-Fi, Pirate, and Zombie stories.
- **Interactive UI**: Clean input fields with auto-formatting.
- **Randomized Stories**: Get a new story every time.
- **Downloadable**: Save your Mad Libs as a `.txt` file.
- **Celebration Effects**: Balloon animations on story generation!
